# Nikon 1 J5 / V2：日本版機身改用繁體中文

[English](README.md) | 繁體中文

日本版的 Nikon 1 機身，語言選單只有 **English** 和 **日本語**，但韌體裡其實包含所有語言。這裡的腳本會修改韌體，讓日本版機身可以使用**繁體中文**：

- **J5**：完整的 32 種語言選單，名稱正確顯示；繁體中文、日文和其他語言都能選，關機後也會保留。
- **V2**：**日本語** 這個選項改為顯示、儲存並在開機時套用繁體中文。

本儲存庫**只有腳本**，不含任何 Nikon 或 XCQi 的韌體檔。請自行下載原始檔案，再用腳本在自己的電腦上修改。

| 相機 | 基礎韌體（輸入檔） | 腳本 | 結果 | 實測 |
|---|---|---|---|---|
| Nikon 1 **J5** | **XCQi 自製韌體 `J5_0101_patched_v11.bin`**：[release j5-patched-v11](https://github.com/XCQi/Nikon-1-custom-firmware/releases/tag/j5-patched-v11) | `patch_j5.py` | 32 種語言 | 日本版 J5 一台 |
| Nikon 1 **V2** | **Nikon 官方韌體 C1.22**（`V2__0122.bin`，A 1.22／B 1.21）：[Nikon 下載中心](https://downloadcenter.nikonimglib.com/en/download/fw/267.html) | `patch_v2.py` | 日本語 → 繁體中文 | 日本版 V2 一台 |

- **J5 版是修改 XCQi 的 patched v11**，不是修改 Nikon 原版韌體。v11 的所有功能都會保留（Wi-Fi／刪除鍵指派、手動對焦放大設定、Fn2、手動鏡頭支援、FT1 改進、1 秒間隔拍攝）。這些功能與限制請參閱 [XCQi 的 J5 說明](https://github.com/XCQi/Nikon-1-custom-firmware/blob/main/cameras/J5/README.md)。
- **V2 版是修改 Nikon 原版韌體。**

> **免責聲明**：這是非官方、實驗性質的韌體修改，與 Nikon 及 XCQi 無關。刷寫修改過的韌體風險自負。每個版本都只在一台相機上測試過。原始韌體的著作權屬於 Nikon；J5 的基礎版本為 XCQi 的作品。

## 修改後的效果

**J5**

- 語言選單列出全部 32 種語言，每個名稱都用自己的文字顯示（Български … 简体中文、繁體中文、हिन्दी、日本語、한글、فارسی、ภาษาไทย）。阿拉伯文和波斯文靠右對齊，與國際版相同。
- 選 **繁體中文**，關機後仍會保留，日文也照樣可以選。

**V2**

- 語言選單仍然是兩項：**English** 和 **日本語**。
- 選 **日本語**，整個介面會變成**繁體中文**，關機再開機後也會保留。
- 選項名稱仍顯示 **日本語**（原因見[已知限制](#已知限制)），也無法使用日文。

## 需求

Python 3.8 以上，不需要安裝其他套件。

## 使用方式

### J5

1. 從 [XCQi 的 release j5-patched-v11](https://github.com/XCQi/Nikon-1-custom-firmware/releases/tag/j5-patched-v11) 下載 `J5_0101_patched_v11.bin`。
2. 執行：
   ```sh
   python3 patch_j5.py J5_0101_patched_v11.bin -o J5_0101_patched_v11_alllang.bin
   ```
   腳本會先核對輸入檔的 SHA-256 和 CRC，套用修改後重新計算 CRC、重新加密，最後確認輸出與實測版本完全相同。

### V2

1. 從 [Nikon 下載中心](https://downloadcenter.nikonimglib.com/en/download/fw/267.html) 下載 C1.22 韌體，取出 `V2__0122.bin`：Windows 執行 `F-V2-V122W.exe`，macOS 開啟 `F-V2-V122M.dmg`，檔案在 `V2Update/` 資料夾裡。
2. 執行：
   ```sh
   python3 patch_v2.py V2__0122.bin -o V2__0122_zhTW.bin
   python3 patch_v2.py V2__0122.bin --restore -o V2__0122_stock_restore.bin   # 選用：之後想還原時使用
   ```

## 安裝到相機

請使用充飽電的電池，更新過程中不要關機或取出記憶卡。

1. 把輸出檔複製到記憶卡**根目錄**，卡上只放這一個 `.bin`。
   - **V2**：檔名改成 `V2__0122.bin`（中間兩個底線）。
   - **J5**：實測時直接用原檔名即可；如果沒有出現更新選項，改名為 `J5_0101.bin`。
2. 進入**設定選單 → 韌體版本 → 更新**，依畫面指示操作。
3. 更新後打開**語言**選單：
   - **J5**：選 **繁體中文**。
   - **V2**：選第二項 **日本語**，選單就會變成繁體中文。

   更新韌體可能會重設語言，必要時再選一次。
4. 關機再開機，確認設定有保留。

版本畫面仍會顯示原本的版本號，這是正常的。

## 還原

- **J5**：安裝 XCQi 的 `J5_0101_stock_restore.bin` 可恢復原廠功能（詳見 XCQi 的說明）。也可以安裝 XCQi 原本的 `J5_0101_patched_v11.bin`，但在日本版機身上，它的語言畫面仍只準備兩列，語言清單可能無法正常運作；安裝前請先切回 English 或日本語。
- **V2**：用 `--restore` 產生 `V2__0122_stock_restore.bin`，改名為 `V2__0122.bin` 後安裝。它是 Nikon 官方 C1.22，只把版本標記提高到 `1.2201`，因為已經是 C1.22 的機身，可能會拒絕重裝完全相同的官方檔。

如果選單變成看不懂的語言：**韌體版本**和**語言**在設定選單中的位置跟原本一樣。

## 已知限制

- **J5**：實機只檢查了語言選單與繁體中文，其他語言的選單內容沒有逐一檢查。
- **V2：名稱仍顯示「日本語」，也無法使用日文。** 語言清單裡的每個名稱都用各自固定的字型繪製；把名稱換成「繁體中文」時顯示成四個方塊，所以名稱維持不變。
- **V2**：韌體中有少數版面配置是依「語言設定是否為日文」決定的，現在會套用在繁體中文畫面上。測試時沒有發現問題。
- 每個版本都只在一台日本版機身上測試過，其他機身、其他地區版本或其他韌體版本的行為未知。請勿用於其他型號。

## 原理

### 封裝、加密與 CRC（J5、V2 共通）

Nikon 1 的韌體封裝使用 Nikon 舊式的 XOR 加密：前 32 bytes 為明文標籤，之後第 *i* 個 byte 與三張 256-byte 的表做 XOR，分別以 *i* 的第 0–7、8–15、16–23 位元為索引。每個模組結尾都有 CRC-16/XMODEM，讓整個模組的餘數為零；整個封裝最後還有一組以相同方式計算的外層 CRC。`nikonfw.py` 實作了這些處理，XOR 表來自 Simeon Pilgrim 的 Nikon Hacker 工具。

### 日本版機身的限制在哪裡

地區記錄在相機內（屬性 1，0 = 日本）。在 J5 上，與語言有關的是以下三處：

1. **項目遮罩**：32 個語言項目各有一段 32 bytes 的條件遮罩，第 27 個 byte 為 `0x80` 時，該項目在日本機上隱藏，只有 English 和日本語不隱藏。它決定清單顯示幾列，**也決定**哪些語言設定值在重開機後會被保留：旗標還在時，選其他語言會立即生效，但重開機就回到日文。
2. **語言畫面**：畫面會讀取地區，日本機就用自己的兩項清單（English、日本語），而不是國際版的 32 項清單。在遮罩仍有效的情況下只強制改這一處時，畫面出現兩列，顯示 Български 和 Čeština，因為遮罩仍只允許兩列。
3. **名稱字型**：清單畫每個名稱時，會暫時切換到該語言。這個暫時切換使用的是第二組精簡字型，其中阿拉伯文和印地文字型缺少這些名稱需要的字形（阿拉伯文、波斯文顯示成方塊，印地文缺 न्द 連寫字）。正式切換介面語言則使用完整字型。

XCQi 的 v11 清除了遮罩（第 1 點），`patch_j5.py` 再加上第 2、3 點，讓 J5 的語言選單表現得跟國際版一樣。V2 仍有相當於第 1 點的限制，所以改為保留機身會接受的設定值 **0x18**，只改變 0x18 所**代表**的語言。

### J5（基礎：XCQi patched v11）

執行位址 = 映像檔位移 + `0x80000`；映像檔從封裝位移 `0x50` 開始。

| 修改 | 執行位址 | 封裝位移 | Bytes |
|---|---|---|---|
| （XCQi v11）清除 30 個語言項目的日本機隱藏旗標，即各 32-byte 遮罩的第 27 個 byte | `0x0144F37B` + `0x20`·k | `0x13CF3CB` + `0x20`·k | `80` → `00`（v11 已內含） |
| 語言畫面初始化：地區讀取 `bl 0x3C5554` → `movs r0,#1; str r0,[r3]` | `0x00424B90` | `0x3A4BE0` | `a0 f7 e0 fc` → `01 20 18 60` |
| 語言畫面按鍵處理：同樣的替換 | `0x00424E00` | `0x3A4E50` | `a0 f7 a8 fb` → `01 20 18 60` |
| 暫時切換語言的字型取得跳轉：第二組 `0x5AF1B0` → 第一組 `0x5AF198` | `0x002F6098` | `0x2760E8` | `b1 f1 5a 00` → `99 f1 5a 00` |
| 內嵌 CRC | — | `0x175A6E0` | 重新計算 |

`0x2F6094` 這個跳轉只有暫時切換語言的函式會呼叫（共 3 處），所以字型修改只影響語言清單。兩組字型的尺寸參數相同。

### V2（基礎：Nikon 官方 C1.22）

模組 A 的執行位址 = 映像檔位移 + `0x50020000`；模組 A 從封裝位移 `0x70` 開始。只修改資料，未修改任何程式碼。

| 修改 | 執行位址 | 封裝位移 | Bytes |
|---|---|---|---|
| 設定值 → 顯示語言對應表，第 0x18 項：0（日文）→ 9（繁體中文） | `0x50C59350` | `0xC393C0` | `00` → `09` |
| 同一張對應表的第二份副本，第 0x18 項：0 → 9 | `0x50CC0FAC` | `0xCA101C` | `00` → `09` |
| 模組 A 版本標記 `Ver.1.2200` → `Ver.1.2201`（讓已是 C1.22 的機身出現更新選項） | — | `0xC1` | `30` → `31` |
| 模組 A 的 CRC | — | `0x1423EE0` | 重新計算 |

顯示語言編號是韌體字串表與字型表使用的索引：8 = 簡體中文，9 = 繁體中文。模組 B（`bx0830_12100`，B 1.21）未修改。修改版本標記的做法參考了 XCQi 在 J5 上的發現：更新檢查比對的是主映像檔標頭裡的版本標記。
